💊 Medicine Label Translator

An AI-powered web application that translates and explains medicine labels in simple, user-friendly language. It helps users understand prescriptions, medicine packaging, and medical instructions in different languages with clarity and accuracy.

✨ Features
🌐 Multi-language Translation – Translate medicine labels into local languages
🧠 AI Explanation – Understand complex medical terms in simple words
📸 Image/Text Input Support – Scan or paste medicine information
⚡ Fast Response System – Quick interpretation of medical labels
🏥 Healthcare Focused – Designed for patient safety and clarity
📱 Responsive UI – Works on mobile, tablet, and desktop

🛠️ Tech Stack
Frontend: React / Next.js (or your stack)
Backend: Node.js / Express (if used)
AI Model: Gemini API / OpenAI API
OCR (optional): Tesseract.js / Google Vision API
Deployment: Vercel / Render

🧠 How It Works
User uploads or enters medicine label text/image
System extracts text using OCR (if image input)
AI model translates and simplifies the content
Output is shown in easy-to-understand format
